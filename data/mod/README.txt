FRIK Experimental - Release Install Notes
=========================================

This hFRIK build is the temporary FRIK dependency for ROCK v0.5.
Install FRIK Experimental before installing or using ROCK v0.5.

The dependency is temporary. It is required only until the hFRIK modifications
are merged upstream into:

github.com/rollingrock/Fallout-4-VR-Body

Install this package as a normal FRIK/Fallout 4 VR Body mod. The plugin still
loads as:

Data\F4SE\Plugins\FRIK.dll

Config Files location:
%USERPROFILE%\Documents\My Games\Fallout4VR\FRIK_Config

Logs location:
%USERPROFILE%\Documents\My Games\Fallout4VR\F4SE

- FRIK.log for FRIK logs
- crash-<date time>.log for crash logs
